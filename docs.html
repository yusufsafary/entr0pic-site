How it works

Mint on this site

  • Connect any BNB Chain wallet.
  • Agent ID holders: read a question drawn from your wallet, type an answer, mint free.
  • Everyone else: pay a tier price shown in a console. Price follows works you already hold: 0.0002, 0.0004, then 0.0008 BNB.
  • Max 20 works per wallet. Supply is 3.333.

Mint through an agent

Agentic Wallet users can skip a browser entirely. Give your agent a skill file at entr0pic-skill.md on this domain. It carries contract addresses, a free-mint question flow, paid tiers, and claim calls with exact fees.

Claim

  • Enter a work number in a claim console. If it is yours and no door was taken, both doors open.
  • KEEP: pay a small BNB fee, receive 250.000 $TR0PIC, work stays alive.
  • COLLAPSE: pay a higher BNB fee, work burns, receive a current Collapse Index amount.
  • Legacy: enter an old Nº 1 to 424, check snapshot status, claim 250.000 $TR0PIC with no fee.
